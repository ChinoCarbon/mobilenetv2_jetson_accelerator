## 指标说明

| 指标 | 含义 | 关注场景 |
|------|------|----------|
| mean_ms | 平均单张推理延迟 | 整体性能 |
| p50_ms | 中位数延迟 | 典型情况 |
| p95_ms | 95 分位延迟 | 大多数情况最差 |
| p99_ms | 99 分位延迟 | 极端情况，边缘部署重点 |
| throughput_fps | 每秒帧数（= 1000 / mean × batch） | 吞吐对比 |
| 峰值显存 MB | `torch.cuda.max_memory_allocated()` | 内存受限平台 |
| FPS/W | 能效，`tegrastats` 采集功耗 | Jetson 边缘价值 |
| 数值误差 | `max(|ours - pytorch|)`，验证正确性 | 算子实现验证 |
| F1（macro） | 各类平均 F1，比 accuracy 更公平 | 不均衡数据集 |

## 计时规范

- warmup：100 次（排除 JIT 编译、内存分配抖动）
- 计时：`torch.cuda.Event(enable_timing=True)`，单次 forward
- 同步：每次 `torch.cuda.synchronize()` 后读取
- iterations：500 次，取排序后百分位
